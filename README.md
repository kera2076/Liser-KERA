# KERA | محاكي أطوال موجات الليزر وتصنيف البشرة
### Clinical Laser Photothermolysis & Fitzpatrick Scale 3D Simulator

مشروع محاكاة علمية وطبية تفاعلية ثلاثية الأبعاد مبنية بالكامل بالأكواد البرمجية القياسية (`HTML5` / `CSS3` / `JavaScript` / `Three.js`) بدون أي حاجة لرفع مجسمات ثلاثية الأبعاد خارجية.

يحمل التطبيق شعار قناة **KERA** في الأعلى ويتميز بواجهة وتصميم طبي سريري عالي الدقة (Clinical Laboratory Aesthetics) بعيداً عن القوالب النمطية.

---

## 🌟 الميزات الرئيسية

1. **نمذجة ثلاثية الأبعاد إجرائية 100% (Procedural 3D Mesh)**:
   - مقطع تشريحي للجلد: الطبقة القرنية والبشرة السطحية (Epidermis)، الأدمة (Dermis)، والنسيج الدهني تحت الجلد (Hypodermis) مع كرات دهنية وشعيرات دموية دقيقة.
   - بصيلة الشعر (Hair Follicle): ساق الشعرة مع إمكانية تغيير السُمك (وبرية، متوسطة، سميكة) واللون (أسود، بني، أشقر، أبيض)، وجذر الحليمة الجلدية (Dermal Papilla).
   - قبضة الليزر الطبية (Laser Handpiece): فوهة ليزر مع حلقة تبريد الياقوت المثلج (Chilled Sapphire Ring) ومؤشر منطقة الاستهداف (Spot Size).
   - حزمة فوتونات متحركة وشعاع مخروطي يتغلغل داخل الجلد ويتشتت بحسب الطول الموجي.

2. **محاكاة فيزياء التحلل الضوئي الحراري الانتقائي (Selective Photothermolysis)**:
   - **Alexandrite 755nm**: امتصاص فائق للميلانين مع نفاذية متوسطة (~2.4mm).
   - **Diode 808nm**: توازن مثالي بين عمق النفاذية (~3.8mm) وامتصاص الميلانين.
   - **Nd:YAG 1064nm**: المعيار الذهبي والآمن للبشرة الداكنة، يتجاوز صبغة البشرة السطحية ويخترق حتى عمق ~5.5mm.

3. **محاكاة حروق البشرة الحقيقية والتنبيهات السريرية**:
   - عند إطلاق ليزر 755nm على بشرة داكنة (Fitzpatrick V أو VI)، يمتص ميلانين البشرة معظم الطاقة مسبباً ارتفاعاً حاداً في حرارة السطح (>70°C)، وظهور فقاعات وتوهج حارق على مجسم الجلد، مع انطلاق صفارة إنذار طبية ورسالة تحذير سريرية واضحة.
   - عند استخدام Nd:YAG 1064nm على نفس البشرة الداكنة، يمر الضوء بأمان ويدمر جذر الشعرة بفعالية تامة.

4. **توليد الأصوات برمجياً (Web Audio API)**:
   - صوت شحن المكثفات، صوت إطلاق النبضة "Zap"، صوت رذاذ التبريد، وإنذار الحروق الطارئ يتم توليدها جميعاً بالأكواد دون الحاجة لملفات صوت خارجية.

5. **رسم بياني طيفي تفاعلي (Optical Absorption Spectrum Chart)**:
   - منحنى امتصاص الميلانين، الهيموغلوبين، والماء مع خط إرشادي حي لموقع طول الموجة المختار.

## 🚀 طريقة الرفع المباشر على GitHub Pages

المشروع عبارة عن موقع ستاتيك (Static Website) بالكامل، ويمكن رفعه وتشغيله على GitHub Pages في أقل من دقيقة:

1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع جميع ملفات هذا المجلد (`index.html`, مجلد `css/`, مجلد `js/`, `README.md`) إلى المستودع.
3. ادخل إلى إعدادات المستودع: **Settings** > **Pages**.
4. من قسم **Branch**، اختر الفرع الرئيسي `main` واضغط **Save**.
5. خلال ثوانٍ، سيعطيك GitHub رابط موقعك المباشر ليعمل أمام الجميع بدون أي خادم!

## 💻 التشغيل المحلي (Local Preview)

يمكنك تشغيل المحاكي محلياً بأي طريقة من الطرق التالية:

- **الخيار الأول (باستخدام بايثون)**:
  افتح موجه الأوامر داخل هذا المجلد واكتب:
  ```bash
  python -m http.server 8000
  ```
  ثم افتح المتصفح على: `http://localhost:8000`

- **الخيار الثاني (باستخدام VS Code Live Server)**:
  انقر بالزر الأيمن على `index.html` واختر **Open with Live Server**.
